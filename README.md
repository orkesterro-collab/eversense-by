# EVERSENSE Беларусь

Адаптивный статический сайт на HTML, CSS и JavaScript. Структура построена по официальному каталогу EVERSENSE и адаптирована для Беларуси.

Страницы: главная, каталог, три серии, 30 отдельных карточек декоров, о бренде, проекты, укладка, гарантия, укладчики, где купить, контакты, документы, конфиденциальность, карта сайта.

Общие шаблоны, поиск и данные по коллекции: `assets/eversense.js`; единые стили: `assets/eversense.css`. Изображения из бренд-материалов: `assets/img/`.

**Статус: предварительная версия.** В `index.html` и зеркале исходных страниц Tilda используются доступные публичные оригинальные изображения и видео. Цены BYN и список магазинов ещё уточняются. Индексация закрыта до согласования.
