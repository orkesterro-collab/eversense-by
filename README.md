# EVERSENSE — сайт дистрибьютора

Сайт официального дистрибьютора напольных покрытий EVERSENSE. Сначала для Беларуси, потом для Казахстана.
Дизайн и тексты взяты с [ever-home.ru](https://ever-home.ru/), цвета, шрифт и графика — из бренд-бука.

Сайт на WordPress: своя тема `eversense` и плагин Polylang для языков (русский и белорусский).

## Что есть на сайте

| Страница | Адрес (RU / BE) | Что внутри |
|---|---|---|
| Главная | `/` и `/be/` | Все блоки ever-home.ru: первый экран со слайдами, награда, «Баланс красоты и практичности», «Дерево? — Сто процентов», ощущения, преимущества, слои, серии, экология, текстуры для дизайнеров, доверие, контакты |
| Каталог | `/catalog/` | Три серии, 30 декоров с артикулами |
| Серия | `/series/quiet-luxury/` | Описание серии, её декоры, переход к следующей |
| Декор | `/catalog/natural-victoria-oak/` | Характеристики, преимущества, кнопка «Где купить», другие декоры серии |
| Где купить | `/where-to-buy/` и `/be/dze-nabyc/` | Магазины по городам, фильтр по городу, Яндекс Карта |
| Политика | `/privacy/` | Шаблон политики конфиденциальности по закону РБ № 99-З |

## Запуск на своём компьютере

Нужен [Docker Desktop](https://www.docker.com/products/docker-desktop/).

```bash
cp .env.example .env
docker compose up -d
docker compose run --rm cli
```

Последняя команда один раз ставит WordPress, Polylang, включает тему и заполняет сайт: языки, страницы, серии, декоры и информационные страницы (без вымышленных магазинов).
Потом откройте http://localhost:8080, админка — http://localhost:8080/wp-admin (логин и пароль `admin` / `admin`, меняются в `.env`).

## Перенос на хостинг

1. Установите WordPress на хостинге (обычно есть установка в один клик).
2. Загрузите папку `wp-content/themes/eversense` в `wp-content/themes/` на хостинге (через FTP или файловый менеджер), либо заархивируйте её в zip и загрузите в «Внешний вид → Темы → Добавить».
3. Установите и активируйте плагин **Polylang**, затем активируйте тему EVERSENSE.
4. В `wp-config.php` добавьте строку `define( 'EVERSENSE_COUNTRY', 'by' );`
5. «Настройки → Постоянные ссылки» → «Название записи».
6. Заполните сайт стартовым контентом. Если на хостинге есть WP-CLI: `wp eversense seed`. Если нет — проще перенести готовый сайт с локальной копии плагином All-in-One WP Migration или Duplicator.

## Что редактируется в админке

- **Каталог → Декоры** — название, отделка, артикул, характеристики, фото текстуры («Изображение записи») и фото в интерьере. Пока фото нет, вместо него показывается заглушка цвета декора.
- **Каталог → Серии** — название, описание, фото серии, порядок вывода.
- **Где купить** — магазины партнёров: город, адрес, телефон, режим работы, сайт, координаты для карты.
- **Внешний вид → Настройки EVERSENSE** — контакты дистрибьютора на обоих языках, реквизиты, соцсети, ссылки на буклеты и сертификаты, видео, все фото главной, ключ Яндекс Карт, номер Яндекс Метрики.
- **Внешний вид → Настроить → Свойства сайта → Логотип** — загрузите фирменный логотип (SVG или PNG). Пока его нет, выводится слово EVERSENSE шрифтом Manrope.

Каждый декор, серия и магазин существует в двух языках, связанных в Polylang: переключайте язык флажками в списке записей.

Тексты главной страницы лежат в файлах темы: `lang/ru.php` и `lang/be.php`.

## Казахстан

Тема уже рассчитана на несколько стран. Для сайта Казахстана:

1. В `.env` (или `wp-config.php`) поставьте `EVERSENSE_COUNTRY=kz`.
2. Контакты-заглушки и языки (русский + казахский) уже описаны в `config/countries.php`.
3. Добавьте файл `lang/kk.php` с переводом — пока его нет, казахская версия показывает русские тексты интерфейса.
4. В `data/catalog.php` добавьте ключ `kk` к сериям и декорам для автоматического заполнения.

## Структура темы

```
wp-content/themes/eversense/
├── config/countries.php      страны: языки, контакты по умолчанию, центр карты
├── data/                     стартовый контент: каталог, страницы, примеры магазинов
├── lang/ru.php, be.php       тексты интерфейса и главной
├── inc/                      логика: типы записей, поля, настройки, иконки, WP-CLI
├── template-parts/home/      блоки главной — по файлу на блок
├── assets/css, js, img       стили, скрипты, паттерн линий дерева
└── front-page.php, archive-ev_decor.php, taxonomy-ev_series.php,
    single-ev_decor.php, page-where.php, page.php, 404.php
```


## EVERSENSE Беларусь: новые возможности (октябрь 2026)

В GitHub добавлены настоящие фирменные WebP-фотографии из папки \`Eversence.by\` Google Диска и архив официального шрифта \`assets/fonts/Manrope.zip\`. На работающем сайте, если нет локальных распакованных шрифтов, Manrope подгружается из Google Fonts; в финале шрифт лучше разместить локально.

### Цены в BYN/м² через Google Таблицу

1. Создайте Google Таблицу с заголовками **sku,price,sale_price**. \`sku\` должен точно совпадать с артикулом декора, например \`EL1052\`. \`price\` — обычная цена, \`sale_price\` — акция, при отсутствии акции поле пустое.
2. «Файл → Поделиться → Опубликовать в интернете» → вкладка/лист в формате **CSV**. Копируйте выданную ссылку вида \`https://docs.google.com/spreadsheets/d/e/.../pub?output=csv\`.
3. WordPress: **Внешний вид → Настройки EVERSENSE → Документы и файлы → Google Таблица с ценами**. Сохраните URL.
4. Каталог и отдельные карточки декоров обновляются автоматически примерно раз в 15 минут, без изменения кода. Если таблица недоступна, показывается «Цена уточняется», а не выдуманная стоимость.

Прайс публикуется в интернете; не добавляйте в него закупочные цены или конфиденциальные данные. Шаблон: \`docs/prices-example.csv\`.

### Проекты

**Реализованные проекты → Добавить проект**: задайте название, описание, изображение записи (обложка), список ID фотографий из Медиатеки, в поле «Артикулы декоров» укажите один или несколько кодов через запятую. После публикации проект появится по адресу \`/projects/\`. Из карточек связанных декоров на него появится ссылка. Обратные ссылки на декоры показываются на странице проекта.

### Укладчики

**Укладчики → Добавить**: имя/организация, город, телефон, сайт/портфолио, фотография, описание. Отметка «Проверен дистрибьютором» ставится вручную только после реальной проверки компетенций. Контакты публикуются лишь с согласия исполнителя. Список: \`/installers/\`.

### Гарантия и укладка

Команда \`wp eversense seed\` теперь создаёт служебные страницы \`/warranty/\` и \`/installation/\` (русская и белорусская версии). Текст в них начальный, официальные инструкции и гарантийные условия нужно уточнить до запуска. Для обновления постоянных ссылок после установки новой темы выполните \`wp rewrite flush\` или пересохраните «Настройки → Постоянные ссылки».

### Предварительный просмотр

В отдельном архиве \`eversense-preview.zip\` есть интерактивный HTML-макет будущей главной. Это **не** рабочий WordPress и не публичная ссылка: он показывает визуальную концепцию, адаптивность и поведение каталога. Для работающего WordPress понадобится PHP-хостинг с базой данных. GitHub Pages не исполняет WordPress/PHP.
